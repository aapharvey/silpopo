# Нотатки для супроводу (silpopo)

Застосунок підтримує Claude; власник репозиторію не програміст. Користувачка — дружина власника, веде списки.
Мова інтерфейсу, повідомлень і коментарів — українська.

## Обмеження, яких треба дотримуватись
- Лише **безкоштовний** Cloudflare: 10 мс CPU і 50 підзапитів (fetch + D1) на запуск, 5 cron на акаунт. Тому:
  збирач — маленькі порції, БД-запити — через `db.batch`, без важких бібліотек.
- Секрети (токен бота тощо) — тільки через Cloudflare Secrets, ніколи в код/коміти.
- Деплой: push у `main` → Cloudflare Workers Builds (міграції застосовуються автоматично).
  Нова зміна схеми = новий файл у `migrations/`, ніколи не редагувати застосовані.

## Структура
- `src/index.ts` — fetch (API, вебхук, статика) і scheduled (збирач, дайджест).
- `src/api.ts` — REST для веб-інтерфейсу (Hono, `/api/*`), за Cloudflare Access (`src/auth.ts`).
- `src/silpo/` — джерело даних: `mock.ts` (тестові), `mcp.ts` (офіційний MCP Сільпо; `TOOL_MAP` і розбір відповідей заповнити після огляду інструментів).
- `src/jobs/collect.ts` — черга перевірки цін; `src/deals.ts` — зведення по позиціях; `src/analytics.ts` — вердикти, цикли акцій, поради.
- `src/telegram.ts` — бот (прив'язка через `/start КОД`, додавання товарів, дайджест).
- `public/` — веб-інтерфейс без фреймворків (mobile-first).
